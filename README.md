# secret-scanner-lite

> Git deposunda yanlışlıkla paylaşılmış gizli anahtarları bulan tarayıcı

Bu depo aktif geliştirme altındadır. Amaç; Linux, Windows ve Termux üzerinde kolay kurulabilen, açık kaynak ve topluluk katkısına uygun bir başlangıç sunmaktır.

## Durum

**Başlangıç sürümü / scaffold.** Özellikler aşamalı olarak eklenecektir.

## Kurulum

### Linux

```bash
git clone https://github.com/cyberorji/secret-scanner-lite.git
cd secret-scanner-lite
```

### Windows (PowerShell)

```powershell
git clone https://github.com/cyberorji/secret-scanner-lite.git
Set-Location secret-scanner-lite
```

### Termux

```bash
pkg update
pkg install git
git clone https://github.com/cyberorji/secret-scanner-lite.git
cd secret-scanner-lite
```
